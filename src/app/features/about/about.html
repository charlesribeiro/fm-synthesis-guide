About & disclaimer

What this is

DX7 Algorithm Lab is an unofficial, educational web application for learning six-operator FM/phase-modulation synthesis through the Yamaha DX7's 32 operator-routing algorithms. It is built with Angular 22 and the Web Audio API.

Disclaimer

This project has no affiliation with Yamaha Corporation or the Dexed project. "Yamaha" and "DX7" are used descriptively, to refer to the historical instrument this app teaches. No copyrighted ROMs, commercial patch banks, sampled performances, proprietary manuals, or copied interface artwork are bundled with this application — all patches, sounds, and diagrams are generated from this project's own code and data.

The audio engine is an educational approximation. Early versions synthesize sound with the browser's native OscillatorNode/GainNode graph, which is a teaching aid, not a bit-accurate emulation of the DX7's original YM21290 sound chip. A more accurate six-operator AudioWorklet phase-modulation engine is a later architectural goal; this app does not claim exact hardware fidelity at any point unless that claim has been independently verified.
