Routed algorithm playback (Phase 8, envelopes in Phase 9)

Plays the selected algorithm through the same setAlgorithm, setOperatorParameters, setFeedback, and (Phase 9) setGate messages WorkletSynthEngine posts against the live app — not only the Phase 7 single-operator and additive proof cases above. The kernel's own six per-operator envelope generators are the only amplitude shaping on this path; changing the algorithm, the feedback depth, or the envelope preset while a note is sounding re-patches it live, without stopping the note or restarting the envelopes.
