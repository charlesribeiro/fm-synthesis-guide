# Roadmap seed for GSD

## Milestone 1 — Foundation and first lesson

### Phase 1: Angular 22 foundation

- Scaffold Angular 22 in repository root.
- Standalone, zoneless, strict, Vitest.
- App shell, lazy routes, SCSS design tokens.
- Quality commands and CI-ready scripts.
- Accessibility baseline and project disclaimer.

### Phase 2: Algorithm domain

- Typed graph model.
- Canonical 32-algorithm dataset.
- Dataset validation and invariant tests.
- Carrier/modulator derivation.
- Fixture algorithms for isolated tests.

### Phase 3: Signal instrument state

- Patch/operator models.
- Signal facade with immutable updates.
- A/B snapshots and reset.
- Unit tests for derived state.

### Phase 4: Algorithm browser and SVG

- 32-item selector/browser.
- Data-driven accessible SVG.
- Algorithm detail route.
- Highlight carriers, modulators, edges, and feedback.

### Phase 5: First playable approximation

- Injected browser audio boundary.
- Monophonic educational engine.
- On-screen/computer keyboard.
- Note lifecycle and cleanup.
- Safe master volume.

### Phase 6: Guided lessons for Algorithm 32 and Algorithm 1

- Lesson framework.
- Additive-synthesis lesson using Algorithm 32.
- Modulation-stack lesson using Algorithm 1.
- Interactive “try this” checks.
- First end-to-end vertical slice.

## Milestone 2 — Serious synthesis engine

### Phase 7: AudioWorklet DSP foundation

- Worklet build/loading.
- Pure six-operator DSP kernel.
- Single operator and additive tests.
- Deterministic sample-block tests.

### Phase 8: Algorithm routing and feedback

- All graph topologies in DSP.
- Feedback state.
- Bounded output and stability tests.
- Switch algorithms without stuck notes.

### Phase 9: DX7-style envelopes and parameter mapping

- Four-rate/four-level envelope model.
- Output-level mapping.
- Ratio/fixed frequency modes.
- Smoothing and release cleanup.

### Phase 10: Visualizers and comparison tools

- Oscilloscope.
- Spectrum.
- Harmonic markers.
- A/B and constrained randomization.

## Milestone 3 — Complete curriculum and portfolio polish

### Phase 11: Curriculum across all 32 algorithms

- Group by recurring structures rather than arbitrary memorization.
- Every algorithm gets a concise lesson, experiment, and original preset.
- Progress tracking.

### Phase 12: MIDI and patch persistence

- Progressive Web MIDI.
- Versioned local persistence.
- JSON import/export.
- Recovery from malformed data.

### Phase 13: Accessibility and performance hardening

- Keyboard-only audit.
- Screen-reader descriptions.
- Reduced motion.
- Mobile/tablet refinement.
- Performance profiling.

### Phase 14: Browser tests and release

- Playwright smoke suite.
- CI.
- Static hosting deployment.
- Screenshots/demo video.
- Architecture and learning-methodology documentation.
