Build the main-thread half of the worklet engine: a DI-wrapped `AudioWorkletNode` boundary with
hand-rolled fakes, and a `WorkletSynthEngine` that implements the existing `SynthEngine` interface
against it — fully tested, and deliberately not wired into the app.

Purpose: D-02's interface-shape proof. `synth-engine.token.ts`'s own doc comment says the
`SYNTH_ENGINE` seam exists so the AudioWorklet engine can swap in without touching UI code; this plan
proves that claim is true today, while D-01 keeps the swap itself for a later phase so Lesson 1's
modulation stack cannot regress on a kernel that cannot route yet.

`audio-context.token.ts` exactly), `testing/fake-audio-worklet-node.ts` (hand-rolled doubles
