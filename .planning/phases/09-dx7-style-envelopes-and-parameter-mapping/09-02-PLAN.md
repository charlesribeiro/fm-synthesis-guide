<objective>
Harden everything plan 09-01 wired: prove no malformed gate or envelope payload can
reach the render thread, prove a full note lifecycle stays bounded and finite,
prove a modulator's envelope actually reaches the ear, prove velocity survived the
removal of the global voice ramp, and protect the already-shipped frequency-mode
math with an explicit regression.

Purpose: the tracer proves the path exists. It does not prove the path cannot be
driven out of bounds, and it does not prove the single highest-impact mistake
available in this phase — an envelope applied only where carriers are summed —
was avoided. That mistake produces output that sounds correctly enveloped while
every modulator's envelope is inert, which is very hard to hear and would pass a
casual listening check.

Output: a mechanical guard for each of this phase's four documented pitfalls, plus
the regression coverage the ROADMAP's frequency-mode success criterion needs.
</objective>

**Lifecycle sweep.** Pick one algorithm from each of the four teaching taxonomy groups by reading its teaching tag from the dataset rather than by hardcoding four ids, so a future dataset change cannot silently narrow the sweep. For each, run the full lifecycle: gate on at maximum velocity, render enough blocks for the attack and the held progression to complete, render a long sustain, gate off, render enough blocks for the release to complete plus a margin. These two cases are the whole mechanical guarantee that removing the dedicated per-voice gain node did not leave the engine able to make sound with no note held.

**Modulator-envelope reachability.** This is the highest-value case in the plan. Choose an algorithm with a real modulation edge and derive its carrier set from the dataset rather than assuming it. Render a reference block with a baseline parameter set. Then change only a modulator-role operator's envelope — leave every carrier's envelope, and every operator's output level, ratio and detune, exactly as they were — re-render from an identically constructed router, and assert the two blocks differ by more than float noise at a stated number of sample positions.
