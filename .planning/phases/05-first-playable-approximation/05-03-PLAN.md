ready, calls `engine.noteOn(note, <a fixed nominal velocity constant>)`, and sets `heldNote`; and
`releaseKey(note)` which calls `engine.noteOff(note)` and clears `heldNote` only when it still

Bind the computer keyboard through the component's `host` metadata (`(document:keydown)`,

cleanup path" discipline the engine follows. The keydown handler returns early, in this order,

held key must sustain one note, not stutter); `event.ctrlKey`, `event.metaKey` or `event.altKey` is

`contenteditable` element (so future Playground text fields keep working); or
`noteForKeyCode(event.code)` returns null. Otherwise it calls `pressKey`. The keyup handler resolves
the same code to a note and calls `releaseKey`. The blur handler calls `engine.allNotesOff()` and
clears `heldNote`, so alt-tabbing mid-note cannot strand a voice.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| DOM pointer/keyboard events → `SynthEngine` | The learner's input crosses into `AudioParam` scheduling here; note values originate from the frozen `PLAYABLE_KEYS` table rather than from arbitrary event data. |
| Document-level key listeners → app | A document-scoped listener sees every keystroke on the page, including ones meant for the browser or a future text field. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-01 | Denial of Service (local) | key input path | medium | mitigate | Note values come only from the frozen `PLAYABLE_KEYS` table, and the engine independently re-validates `note` and `velocity` before any `AudioParam` call (plan 05-01, T-05-01), so no event-derived value reaches Web Audio unchecked. |
| T-05-06 | Denial of Service (usability) | document key listeners | medium | mitigate | The keydown guard rejects modifier-held events and events targeting editable elements, so the play surface cannot swallow browser shortcuts or future text input; four named tests assert the guards. |
| T-05-03 | Denial of Service (resource) | event listeners and held notes | medium | mitigate | Listeners are declared through Angular host bindings with automatic teardown; window blur and `DestroyRef` both call `allNotesOff`, so no navigation or focus change can strand a voice. |
| T-05-SC | Tampering | npm installs | high | accept | No package-manager install occurs in this phase — `05-RESEARCH.md` §Package Legitimacy Audit records zero proposed packages. |
