<objective>
Expand the tracer's thin single-algorithm routing into the generic, data-driven patcher that
handles all 32 algorithms — modulation edges, feedback self-loops through a DelayNode, per-operator
level and frequency conversion — and make an algorithm switch during a held note re-patch that
voice live.

Purpose: D-01 chooses a generic edge-traversal patcher precisely so that "no stuck voices after an
algorithm switch" is true for all 992 ordered switch pairs rather than for a blessed few. That
guarantee only holds if the routing derives from the canonical edge data and nothing else.

Output: `patch-plan.ts` (pure), the full DX7-scale conversion set, and an engine that applies both
against its persistent node graph on every state change.
</objective>
