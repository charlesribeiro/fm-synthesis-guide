## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| File picker bytes -> parseSavedDocument | Untrusted backup file; `accept` is a hint only |
| Confirm dialog -> destructive import/clear | User intent gate (D-25, D-23) |
| Imported strings -> Settings template | XSS if assigned as markup |
| Hydrated lastMidiDeviceId -> Enable MIDI | Must not request access until click (D-08) |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-12-03 | Tampering | Settings import | high | mitigate | `parseSavedDocument` first; Dexed/SysEx fail closed; confirm then replace. |
| T-12-14 | Tampering | XSS via imported strings | medium | mitigate | Bind `recoveryMessage` / import error with `{{ }}` only. |
| T-12-15 | Denial of Service | oversized import | medium | mitigate | Refuse when `file.size > MAX_IMPORT_BYTES` before reading text. |
| T-12-16 | Information Disclosure | auto `enable()` on hydrate | medium | mitigate | Hydrate stores the id; only Enable MIDI calls `request`. |
| T-12-06 | Tampering | Clear saved data | medium | mitigate | `removeItem` of one key; confirm first. |
| T-12-SC | Tampering | npm installs | low | accept | No packages. |
</threat_model>
