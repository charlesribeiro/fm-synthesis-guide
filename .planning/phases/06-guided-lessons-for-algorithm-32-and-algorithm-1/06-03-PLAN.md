<objective>
Replace the Phase 1 placeholder at `/learn` with the real lesson index: one card per `LESSONS` row,
each linking to its own `/learn/:lessonId` page and showing that lesson's completion state from the
`LessonProgress` facade — the same browse-index-to-detail-route shape Phase 4 established for
`/algorithms`.

Purpose: the index is the only in-app entry into a lesson and the only place a learner sees progress
across lessons. Without it the vertical slice has no front door, and the route still tells visitors
the lesson player is unbuilt.

Output: a data-driven `Learn` component, its card markup and styles, and the spec covering both the
data-driven rendering and the index-to-detail round trip.
</objective>
