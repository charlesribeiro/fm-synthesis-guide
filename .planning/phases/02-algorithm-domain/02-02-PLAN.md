<objective>
Turn DOMAIN-04's "domain logic has no Angular dependency" from a convention that is currently
true only by inspection into a gate that fails when it stops being true.

Purpose: RESEARCH.md § Validation Architecture flags this as the one real Wave 0 gap in the
phase — nothing in the repo today fails if a future edit pulls an Angular symbol into a domain
file. DOMAIN-04 would then be silently false while every test still passed. This plan closes
that gap before the domain tree grows from two files to nine.

Output: A scoped `no-restricted-imports` override in `eslint.config.js`, proven to fire by a
deliberate negative control rather than assumed to work.
</objective>
