<objective>
Put the part of this dataset that automated tests cannot judge — whether the routing is
historically right — in front of a human, once, with the work already done for them.

Purpose: DOMAIN-01 through DOMAIN-04 are structural claims and Plan 02-04 already proves them.
Historical fidelity is a different claim, and no test in this repository can settle it: a
consistently wrong row passes every invariant. RESEARCH.md's own Assumptions Log (A1 through A3)
and Open Questions name exactly which rows carry that risk. D-09 assigns the judgement to the
user, on the compiled table, once — not per source, per algorithm.

Output: A review dossier, a recorded sign-off, and any corrections the reviewer names, applied
through the same gate every other row went through.
</objective>
